# Lootstrapped

*Make Something People Loot.*

You run the pawnshop of an adventuring guild, backed by a board of angel investors who must be pleased. You never see the dungeon, only what comes back out of it, so the game is in reading what each item really is and what it is worth to whom. It is built to be complete in about two weeks of AI-assisted work and then grown in place: one browser session plays one season, so it stays small enough to finish, and content is moddable data, so it can keep growing without a rewrite.
