# D-CSQFNAVMFBMTACBM Play happens in bounded seasons between guild vacations

## Context
A shop game can run forever, which leaves it without an ending, a score or a reason to start again.

## Decision
Play happens in bounded seasons: a season is the working period between the guild's collective vacations, when no adventurer works, as in the Swedish industrisemester.

## Why
A fixed end gives each run a shape and a natural verdict, and a reason to come back for the next one. Tying the bound to a guild-wide holiday makes it a fact of the world rather than an arbitrary timer. An endless sandbox was the alternative, and it had neither stakes nor closure.

## Consequences
The season's end is a fixed event the design can build pressure towards. Anything that carries across seasons has to pass through the vacation.
