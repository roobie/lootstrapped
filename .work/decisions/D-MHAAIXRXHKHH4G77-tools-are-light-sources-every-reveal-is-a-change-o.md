# D-MHAAIXRXHKHH4G77 Tools are light sources: every reveal is a change of lighting

## Context
D-H574L6YSCOZIDEGL puts the item in 3D at the counter, and finite tools reveal its clues (D-YX3IUCV2YUN7CT7X); the reveal itself needs a form.

## Decision
Tools are light sources, so every reveal is a change of lighting on the item rather than an icon or a popup.

## Why
A reveal that changes how the item looks is felt before it is read, and it is the strongest reason for the counter to be 3D at all. It also folds tools into the one lighting system that the candle clock (D-34WHPVTJ6MRKUSXM) and the cold rim (D-3ZWBI6KBBWBWWXDJ) already use, so the counter speaks one language.

## Consequences
Each tool carries a lighting rig as data, and the counter scene needs lighting that changes at run time. The clue a tool reveals is still written on vellum, under the legibility rules.
