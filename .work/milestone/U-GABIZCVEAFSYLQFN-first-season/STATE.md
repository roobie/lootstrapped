# milestone/first-season

## Purpose
The game exists: a complete 30-minute session from start to graded verdict, playable in the browser. Everything after it is shaped by what its playtest shows.

## Scope
In: the four fixed slices of the two-week plan (DESIGN.md, Fixed slices), run in order: S0 visual-groundwork → S1 skeleton → S2 shop-day → S3 season; then the first playtest gate.
Out: lending, the dungeon, provenance, reputation, the pre-vacation rush, mob customers, audio and polish, balance pinning (the flexible slices S4–S7, held in the backlog).

## Context & constraints
The slices are sequential, because each builds on the one before it: no slice starts until the previous one is delivered. S0–S3 are fixed and are never cut, because without them there is no game; only what comes after the playtest gate is reshaped. Budget is roughly days 1–8 of the two-week plan.
